# 시험 준비와 오늘의 공부 실행

사용자 요청: 실제 대학생이 반복해서 사용할 수 있도록 서비스의 기능을 강화한다.

## 제공할 흐름

- 시험 날짜·확정 범위·같은 과목 자료를 묶어 준비 계획을 저장한다.
- 여러 계획이 하나의 하루 공부 시간을 나눠 쓴다. 날짜가 가까운 시험을 우선한다.
- 자료 확인·문제 점검·복습을 짧은 작업으로 연결하고 완료·내일로 미룸을 저장한다.
- 가용 시간을 바꾸면 남은 작업을 재배치한다. 완료 기록은 보존하고 마감 전 배치하지 못한 분량은 표시한다.
- 집중 타이머는 일시정지·재개를 지원하며 만료만으로 완료 처리하지 않는다.
- 도래한 복습 문제를 5문제 단위로 시작할 수 있다.
- 시험 범위를 문제 생성 입력으로 연결한다. 확인하지 않은 이해도·점수 예측은 표시하지 않는다.

## 데이터와 경계

소유자별 `study_workspaces` 한 행에 하루 시간과 최대 30개의 계획을 보존한다. 활성 계획은 최대 8개, 계획별 자료는 최대 6개다. 서버가 소유 과목·자료·시험 일정을 검증한 뒤 작업을 생성한다. 날짜는 KST로 처리하고 과거·90일 이후의 새 목표는 거절한다. revision 비교로 동시 편집의 덮어쓰기를 막는다. 일반 클라이언트의 DB 쓰기는 허용하지 않고 읽기에는 owner 및 기존 MFA 정책을 적용한다.

AI 모델·라우팅을 바꾸지 않는다. 계획의 분량과 시간은 실행을 돕는 기본값이며 실제 이해도나 예상 성적을 뜻하지 않는다. 원문 읽기·문제 생성·복습은 기존 학습 경로로 연결한다.

## 검증

일정 배분의 시간 상한·미룸·완료 보존·기한 초과·KST 경계와 API의 인증·소유권·revision 충돌을 테스트한다. 새 SQL은 운영 데이터를 변경하지 않는 임시 스키마에서 RLS·MFA·동시 저장을 확인한다. 브라우저에서 생성·완료·미룸·시간 변경·타이머·실패 복구를 모바일·태블릿·데스크톱으로 확인한다. 마지막으로 타입·린트·빌드와 기존 회귀 검사를 실행한다. 운영 마이그레이션 적용과 배포는 검증 결과와 구분한다.

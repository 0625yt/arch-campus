# 대시보드 홈 — "AI티 제거" 리디자인 설계

**날짜:** 2026-06-04
**브랜치:** `redesign/dashboard-home`
**대상 화면:** `/dashboard` (내 캠퍼스 홈)
**기준:** Apple 순정 앱 (Calendar·Reminders·Fitness 톤) + 기존 디자인 시스템(`globals.css` `@theme`)
**제약:** 구조 변경 없음. 디테일만. 전용 브랜치 → 마음에 안 들면 브랜치 폐기로 완전 롤백.

---

## 1. 배경 / 문제

arch-campus의 메인은 **공부 + 일정**이고, `/dashboard`가 그 첫 인상이다. 현재 화면은 이미 정교하다 — 코발트 단일 accent, elevation 3단계, 회색 절제, 스크롤 없는 한 화면. 큰 구조는 좋다.

그러나 실제 렌더(1200px)를 픽셀·코드로 감별한 결과, **5개 디테일에 "AI가 만든 티"가 남아 있다.** 핵심 통찰:

> **AI티 = 친절한 설명문 + 균일한 반복.** Apple 순정은 *말하지 않고 보여주고*, 같은 grid라도 내용이 다르면 모양도 다르다.

이 spec은 구조를 건드리지 않고 그 5개 디테일만 Apple 순정 톤으로 교정한다. DESIGN §10(좌측 동그라미 점·마침표 카피 남발·generic 모달 금지)과 정확히 일치하는 방향이다.

## 2. 범위

**손대는 파일 (예상):**
- `src/app/dashboard/bottom-cards.tsx` — 3카드 차별화 + 카피 정리 + 진척 표현 + 화살표
- `src/app/dashboard/timetable-hero.tsx` — "지금" 강의 강조 + 시간 라인 (코드 재확인 후 확정)
- `src/app/dashboard/timetable-side-rail.tsx` — 사이드 카피 정리 (코드 재확인 후 확정)
- (필요 시) `src/app/globals.css` — 기존 `now-glow` 등 미사용 토큰 연결. 새 토큰 추가는 최소화.

**범위 밖:** AI 초안 위저드, 퀴즈, 피드백 (별도 화면, 추후). 라우팅·데이터 페칭·DB. 새 기능 추가.

## 3. 수정 항목 (5개)

### 항목 1 — 하단 3카드 차별화 [AI티 높음]

**현재:** `BaseCard` 하나로 긴급·다음일정·강의를 전부 365×104px, radius 14, 동일 레이아웃(label↗ · title · meta)으로 렌더. "템플릿 3개 복붙" 인상.

**개선:** 같은 grid·같은 높이는 유지하되(레이아웃 안정성), **각 카드의 내용물 형태를 성격에 맞게 차별화**한다.
- **긴급 신호:** 좌측에 작은 신호등 점(urgent=코랄 / warn=살구 / calm·muted=점 없음). 위험 없을 땐 점도 없음 — "정상"을 시각적 침묵으로.
- **다음 일정:** D-day를 **큰 숫자**로(tabular-nums, 20px+). "D-4"가 카드의 주인공. 강의명은 보조.
- **강의:** 항목 3과 연동 — 작은 도넛 진척(아래).

세 카드가 "같은 모양"이 아니라 "같은 가족"이 되게. Apple 위젯 패밀리 원칙.

**롤백 안전성:** `BaseCard` prop 확장 또는 카드별 분기. 기존 `tone` 시스템 유지.

### 항목 2 — 카피 정리: 설명문 제거 [AI티 높음]

**현재 (제거 대상):**
- "자료 정리하기 좋은 날"
- "강의계획서 올리면 자동으로 채워져요"
- "오늘은 강의가 없어요. 자료 정리 좋은 시간이에요."
- "강의계획서 한 장이면 시작돼요"

**개선:** 카드는 **말하지 않고 보여준다.** 빈 상태/정상 상태에 친절한 부연을 붙이지 않는다.
- "지금 위험 신호 없음" → 그대로 유지하되 부제("자료 정리하기 좋은 날") **삭제**.
- "오늘 강의 없음" → 끝. 뒤 문장 삭제.
- 빈 상태 유도 문구가 꼭 필요한 곳(다음 일정 없음 등)은 **명사형 한 줄**로: "강의계획서로 자동 채움" 같은 기능 설명이 아니라, 행동 가능한 최소 라벨. (구현 시 케이스별 확정)

**원칙:** 느낌표 0. "~요" 설명체 최소화. 수치·명사 우선. Apple Calendar 빈 상태엔 한 줄도 없다.

### 항목 3 — 진척 표현: generic 막대 → 절제된 형태 [AI티 중간]

**현재:** "1/11 자료 등록 · 9%" + 얇은 파란 progress bar. shadcn 기본형. 9%가 막대로 보이면 "텅 빔"만 강조.

**개선:** 얇은 풀폭 막대 대신 **작은 도넛 링**(Fitness 톤) 또는 수치 강조. 낮은 진척은 "텅 빔"이 아니라 **다음 행동**으로 프레이밍: "11개 중 1개 시작" 같은. 막대를 꼭 유지하면 더 짧고 절제되게.

**결정:** 작은 도넛 링으로. SVG circle 2개(track + progress), 28~32px. tabular-nums 수치 병기.

### 항목 4 — 시간표 "지금" 강조 [AI티 중간]

**현재:** 10개 강의가 전부 같은 파스텔 블록 + 같은 크기 텍스트. "지금 진행 중" 강의도 동일. 어디 볼지 신호 없음.

**개선:** Apple Calendar처럼 **현재 시각 신호**를 준다.
- 지금 진행 중인 강의 블록에 **`now-glow` 적용** (이미 `globals.css`에 정의됨 — 미사용. "추가"가 아니라 "연결").
- (가능하면) 현재 시각 위치에 가는 라인. timetable-hero 구조 재확인 후 확정.
- 지나간 시간대 강의는 옅게(opacity) — 시간 흐름이 보이게. (선택)

**주의:** `now-glow`는 2.4s breathe 애니메이션. `prefers-reduced-motion` 가드는 globals.css에 이미 일괄 적용됨. AI티 안 나게 **현재 강의 1개에만**.

### 항목 5 — "›" 화살표 정리 [AI티 낮음]

**현재:** 모든 카드 우상단 "›" 동일 위치·크기, hover 0.5px 밀림. 4곳 반복 = 장식.

**개선:** 카드 전체가 탭 타깃이므로 **상시 화살표 제거.** hover 시 카드가 떠오르는 것(기존 `-translate-y-px`)으로 클릭 가능성 전달. 화살표가 꼭 필요하면 **hover에만 fade-in.**

**결정:** 상시 제거 + hover fade-in (Apple은 hover 시에만 chevron 노출하는 패턴 많음).

## 4. 구현 순서

1. 항목 2 (카피) — 가장 안전, 텍스트만. 먼저.
2. 항목 5 (화살표) — 작은 제거.
3. 항목 1 + 3 (3카드 차별화 + 도넛) — bottom-cards.tsx 한 파일, 함께.
4. 항목 4 (시간표 now) — timetable-hero.tsx 재확인 후. 가장 신중하게.

각 단계 후 로컬에서 `/dashboard` 직접 확인(§7 검증). 한 화면 끝나면 사용자에게 보여주고 승인.

## 5. 검증

- `npm run dev` → `/dashboard` 실제 렌더 확인 (Playwright snapshot + evaluate로 픽셀 측정)
- `npm run typecheck` + `npm run check` 통과
- DESIGN §10 위반 0 재확인 (좌측 점·마침표 카피·generic 모달 없음)
- 다크모드·모바일(반응형 1급) 깨짐 없음 확인

## 6. 롤백

- 전 작업이 `redesign/dashboard-home` 브랜치. `main`은 무손상.
- 마음에 안 들면: `git checkout main` → 브랜치 폐기. 완전 원복.
- 부분 롤백 필요 시 항목별 커밋 분리돼 있어 `git revert` 가능.

## 7. 비범위 / YAGNI

- 새 디자인 토큰 대량 추가 X — 기존 토큰 재사용, 미사용 토큰(`now-glow`) 연결 우선.
- 런타임 구/신 테마 토글 X — 브랜치로 충분.
- 시간표 데이터 모델·일정 로직 변경 X — 순수 프레젠테이션.

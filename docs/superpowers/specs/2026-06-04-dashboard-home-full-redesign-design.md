# 대시보드 홈 — 전체 재설계 설계

**날짜:** 2026-06-04
**브랜치:** `redesign/dashboard-home` (기존 작업 이어서. main 무손상)
**대상 화면:** `/dashboard` (내 캠퍼스 홈 — 제품의 메인 = 일정 + 공부)
**기준:** Apple 순정 앱 (Calendar 일간뷰 · Fitness · Reminders) 톤 + 기존 디자인 시스템(`globals.css` `@theme`)
**제약:** 전용 브랜치 → 마음에 안 들면 브랜치 폐기로 완전 롤백. 데이터·라우팅·DB 변경 없음. 순수 프레젠테이션.

> **이전 spec 대체:** [2026-06-04-dashboard-home-ai-tell-removal-design.md](2026-06-04-dashboard-home-ai-tell-removal-design.md)는 "구조 변경 없이 디테일만"으로 범위가 좁았다. 사용자 피드백("일부만 고치지 말고 대대적으로, 시간표 잘림도 고쳐라")에 따라 **홈 전체 재설계로 확장**한다. 기존 spec에서 완료된 하단 3카드 정리(신호등 점·D-day·도넛·hover 화살표)는 유지하고 그 톤을 화면 전체로 확장한다.

## 1. 배경 / 문제 (실측 진단)

`/dashboard`를 1280×832에서 픽셀·코드로 감별한 결과, **3개의 구조적 문제**가 확인됐다.

### 문제 ① 시간표가 "한 화면 fit"의 인질 → 작은 화면에서 잘림 [최우선]

현재 대시보드는 **스크롤이 아예 없다**(`page.tsx`: `h-full` + layout의 `overflow-hidden`). 헤더·시간표·하단카드를 뷰포트 높이에 강제로 욱여넣고, 시간표는 남는 공간만 받는다.

- 강의 셀이 `top: calc(${%}%)`, `height: calc(${%}%)` — **컨테이너 높이의 비율**로 배치 (`timetable-hero.tsx:427-451`).
- 1280×832에서 시간표 cells 영역 = **489px**에 9~22시(13시간)를 그림 → 1시간 강의 블록 = **38px**.
- 노트북 13" / 북마크바로 가용 높이가 줄면 489px가 300px대로 압축 → 38px 블록이 20px 이하 → **강의명 잘림·글자 겹침·아래 시간대 소실**.
- 컨테이너 wrapper가 `overflow-hidden`이라 빠져나갈 스크롤도 없음(`timetable-hero.tsx:285`).

### 문제 ② "지금 무엇을 해야 하나"가 한눈에 안 온다

화면을 열면 시간표 격자가 가장 크지만, 정작 지금 중요한 정보(지금 수업 중인지, 다음 강의까지 몇 분)는 우상단 작은 `NowReadout`에 흩어져 있다(`timetable-hero.tsx:140-199`). Apple은 "지금/다음"을 화면에서 가장 크게 보여준다.

### 문제 ③ 여백·타이포에 강약이 없다

한 화면에 다 넣으려다 모든 요소가 균일하게 빽빽하다. 헤더·격자·카드가 비슷한 무게로 경쟁한다. Apple 순정은 큰 여백 + 한 곳의 큰 타이포로 시선을 잡고 나머지는 조용히 둔다.

### (완료) 문제 ④ 하단 3카드 — 1차 정리됨

설명 카피 제거·신호등 점·큰 D-day·도넛 링·hover 화살표 적용 완료(커밋 `bda338a`·`ee8da27`·`fd83a07`). 이 톤을 헤더·시간표까지 확장한다.

## 3. 새 레이아웃 골격 (A안)

세로 스택. **헤더·배너·하단카드는 고정(`shrink-0`), 시간표만 내부 스크롤.**

```
┌─────────────────────────────────────────────┐
│ 봄학기                        [시간표 수정]   │ ← TopChrome (고정, 기존 유지)
│                                               │
│ 윤태경님의 이번 주                            │ ← 헤더: 타이포 강화 (③)
├─────────────────────────────────────────────┤
│ ● 지금 · 글로컬 영어 I    10:50까지           │ ← NowBanner (②, 신규)
│   다음 · 건축설계 11:00 · 12분 후             │   고정. 큰 한 줄.
├──────────────────────────────┬──────────────┤
│ 월  화  수  목  금       ▲    │              │
│ 9  ▓영어        ▓건축史  │스 │  사이드레일  │ ← 시간표(내부 스크롤) +
│10  ▓영어                 │크 │  (lg 이상)    │   사이드 (lg, 기존 유지)
│11    ▓설계  ▓CAD         │롤 │              │
│ ─────────now─────────    ▼    │              │
├──────────────────────────────┴──────────────┤
│ [긴급 신호] [D-4 다음 일정] [강의 진척 ◔]    │ ← BottomCards (고정, 완료됨)
└─────────────────────────────────────────────┘
```

**높이 분배 (dashboard-client.tsx):**
- `TimetableHeading` — `shrink-0`
- `NowBanner` — `shrink-0` (신규)
- 시간표+사이드 grid — `flex-1 min-h-0` (남은 공간), **이 안에서 시간표가 내부 스크롤**
- `BottomCards` — `shrink-0`

모바일(<lg): 사이드레일 숨김(기존). 배너는 유지(오히려 모바일에서 더 중요).

## 4. 컴포넌트 단위 설계

### 4-1. 시간표 픽셀 기반 + 내부 스크롤 [핵심, ①]

**현재:** 셀이 컨테이너 높이의 `%` 비율 → 컨테이너가 작아지면 셀도 축소.
**변경:** **시간당 고정 픽셀(`HOUR_PX`)** 기반으로. 시간표 body 전체 높이 = `(hourEnd - hourStart) × HOUR_PX`로 명시. 이 높이가 컨테이너보다 크면 **내부 스크롤**.

- `HOUR_PX` 상수 도입. 데스크톱 56px, 모바일 64px 정도 (강의명 2줄 + 시각이 안 잘리는 최소 높이). 구현 시 실측으로 확정.
- 셀 `top`/`height`: `%` → `px` (`(startMinute - minuteOffset) / 60 × HOUR_PX`). hour hairline·gutter 라벨·현재시각 라인·오늘 wash·past dim 전부 동일하게 px 기준으로 환산.
- Body wrapper(`timetable-hero.tsx:318`): `overflow-hidden` → **`overflow-y-auto`** (+ gutter는 sticky 또는 함께 스크롤. 헤더 요일 행은 `sticky top-0`).
- 카드 wrapper(`:285`)의 `overflow-hidden`은 **둥근 모서리 클립 용도로 유지**하되, 내부 스크롤 컨테이너를 따로 둔다.
- **"지금"으로 자동 스크롤:** 마운트 시 현재 시각 라인이 보이도록 스크롤 컨테이너를 `nowFrac` 위치로 이동(상단에서 약간 여유). `prefers-reduced-motion`이면 즉시(`behavior: auto`), 아니면 `smooth`.
- **주의:** 이건 "한 화면 fit" 철학을 시간표에 한해 포기하는 변경. 헤더·배너·하단카드는 여전히 고정이라 전체 페이지는 스크롤 안 함 — 시간표 영역 안에서만 스크롤.

### 4-2. NowBanner — "지금/다음" 강조 배너 [신규, ②]

시간표 위 고정 한 줄(2줄까지). `findNowAndNext`(`timetable-grid.ts`)가 데이터 소스.

- **지금 수업 중:** `● 지금 · {강의명}` 큰 글씨(16~18px wght-700) + `{endLabel}까지` 보조. 좌측 점은 `now-glow`와 같은 코발트(상태 표시 — DESIGN §10의 장식용 점과 다름).
- **다음 강의:** 둘째 줄 `다음 · {강의명} {startLabel} · {N}분 후`. N = `next.slot.startMinute - 현재 KST 분`. 컴포넌트에서 계산(데이터에 이미 충분).
- **오늘 강의 다 끝남/없음:** `오늘 일정 마무리` 한 줄(명사형, 느낌표·"~요" 없음 — DESIGN §10).
- 기존 우상단 `NowReadout`은 **배너로 승격되며 제거**(중복 방지). `TimetableHeading`은 인사 타이포만 남김.
- 톤: 카드형 박스 1개. 코발트 hairline + 아주 옅은 코발트 wash(기존 `NowReadout` 스타일 재사용). 친절체 카피 금지.

### 4-3. 헤더 타이포·여백 리듬 [③]

- `TimetableHeading`: 인사 타이포는 이미 큼(`:73` 22→30px). 유지하되, 배너가 생기므로 **우상단 NowReadout 제거**로 헤더가 깔끔해짐.
- 페이지 여백(`page.tsx:43`): 상하 여백 리듬 점검. 배너·시간표·카드 사이 gap이 균일(`gap-3`)인데, **배너↔시간표는 붙이고(연결감), 시간표↔하단카드는 띄워** 그룹을 시각적으로 분리. (`gap` 차등)
- 새 디자인 토큰 추가 최소화 — 기존 `apple-*` 재사용.

### 4-4. 사이드레일 [유지, 미세 조정]

- `TimetableSideRail`은 lg 이상에서 유지. 배너와 정보 중복("지금/다음")이 생기므로 사이드레일의 "지금" 섹션은 **"오늘 남은 강의 리스트"·"다가오는 마감"으로 역할 재배치** (지금/다음은 배너가 담당). 중복 제거.
- Task 1에서 이미 사이드레일 설명 카피는 제거됨.

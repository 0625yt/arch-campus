## 이번 점검에서 수정한 것

- 요약 실패 화면에서 새 파일을 즉시 선택해 같은 과목·제목으로 다시 분석하도록 보완했다.
- 실제 파서가 지원하던 DOCX·PPTX·XLSX·이미지를 업로드 완료 단계에서도 허용하고 60MB 제한 안내를 일치시켰다.
- 비어 있던 설정 주소에 월간 AI 사용량·도구별 횟수·보안 진입 화면을 추가하고, 운영 DB 집계와 사용자별 월 $3 비상 상한을 연결했다.
- 동시 요청이 함께 상한을 통과하던 틈을 0031의 사용자별 DB 잠금과 요청 비용 예약으로 막고, 생성 비용이 기록되면 예약액을 자동 정산하게 했다.
- 8분 이상 멈춘 요약·문제 작업은 저장 입력으로 한 번 자동 재시도하고, 여러 탭의 중복 재실행과 무한 재시도를 막았다.
- 공식 `ts-fsrs`로 문제별 기억 상태와 다음 복습일을 계산하고, 기존 오답 이관·오늘/예정 큐·4단계 체감 난이도 평가를 연결했다.
- 학기 목표 평점·취득학점·회고와 과목별 목표 등급을 저장하고, 실제 성적이 없는 과목까지 포함한 예상 평점과 목표 차이를 계산한다.
- 학기별 시간표 선택, 과목별 학점·등급, 4.5 만점 학기/누적 평점을 구현했다.
- 같은 과목명을 다른 학기에 별도로 보존하도록 학습 공간 주소를 과목 ID 기준으로 전환했다.
- 로그인/가입/OAuth의 `next`를 앱 내부 경로로 제한.
- 시간표 현재 시각·작은 분 표기의 다크 대비 보정.
- 서버와 기기의 시간 차이로 생기는 시간표 첫 화면 불일치 수정·회귀 검사.
- Next.js 16.3.3·OfficeParser 8.0.0 보안 업데이트와 PPTX 파싱 검사.
- 보안 설정에서 미구현 기기 목록을 제공한다고 적힌 설명 정정.
- 환경 검사에서 키 일부 출력 제거, 실제 라우팅 함수 재사용, 읽기 전용 모델 가용성 검사, anon 데이터 노출 판정 수정.

- 보안 패치는 먼저 적용하고 빌드·회귀 검사한다.
- 모델 신제품은 기존 자료 평가 점수·지연·비용을 통과해야 교체한다. ‘최신’ 이름만으로 바꾸지 않는다.

- CSS 3D·모션은 이미 적용했다. 복습·알림 기능 대신 장식 라이브러리를 늘리는 작업은 우선하지 않는다.

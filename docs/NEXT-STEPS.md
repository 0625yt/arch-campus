## 최신 기술 채택 기준

- 보안 패치는 먼저 적용하고 빌드·회귀 검사한다.
- 모델 신제품은 기존 자료 평가 점수·지연·비용을 통과해야 교체한다. ‘최신’ 이름만으로 바꾸지 않는다.
- Supabase `getClaims()`는 요청 비용 절감 후보지만 즉시 서버 세션 폐기 확인과 MFA 요구를 검토하고 도입한다.
- Vercel Workflow 같은 내구성 실행은 긴 생성 작업의 재시도 문제 해결 후보다. 기존 jobs 데이터를 옮기거나 중복 실행하지 않도록 단계적으로 검증한다.
- CSS 3D·모션은 이미 적용했다. 복습·알림 기능 대신 장식 라이브러리를 늘리는 작업은 우선하지 않는다.

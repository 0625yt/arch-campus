## 3. 퀴즈 A/B 재측정 — ✅ 완료 (2026-07-24 **Gemini 3.5 Flash-Lite 확정**)

### 3-1. 결론 (완료)
- **quiz는 Gemini 3.5 Flash-Lite로 prod 확정**. 2026-05-28의 "evidence 0%" 문제는 **강화 파이프라인**으로 해결: verbatim 프롬프트 + validate-quiz evidence 검증 + 의미 dedup(gemini-embedding-001) + 스마트 topup + 2차 검수. 실측 통과.
- **1회 비용 −82%** (Sonnet 대비). quiz는 prod 비용 79.9%라 절감 효과 최대.
- 이전의 isProd 차단 가드는 제거됨 — 이제 prod 기본이 Flash-Lite. 원복은 `QUIZ_MODEL_VENDOR=anthropic`.
- 상세 근거: [COST.md §9](COST.md) A/B 로그 + [MODEL-OPTIONS.md §3-A](MODEL-OPTIONS.md).

### 3-2. 다음 조치 (이전 NEXT-STEPS §2-3 메트릭 그대로 사용)

같은 자료 N개로 Sonnet vs Flash를 나란히 생성 → 4개 모두 동등 이상이어야 통과:

1. **변별력**: 정답률 분포 50~75%
2. **evidence 정확도**: 모든 문제 evidence가 자료 본문 substring 매칭 (현 0% → 목표 90%+)
3. **함정 선택지 품질**: 4개 보기 모두 다른 표현, "전부 정답" 류 제거
4. **한국어 어휘·표현**: 어색한 직역·문법 오류 없음

### 3-3. 무엇을 바꿔야 매칭률이 오를까 (가설)

- 프롬프트 강도 ↑: 현재 prompt가 Anthropic 기준으로 짜여 있어 Gemini가 evidence 형식을 덜 따름. `_shared/master-rules.md`에 "evidence는 자료 본문 substring 그대로" 가드 한 줄을 강화.
- 자료 사전 처리: 본문 청크 길이를 Gemini 컨텍스트 강점에 맞게 조정.
- 다중 샘플: temperature를 낮추고 best-of-3 채택.

- ⚠ 학점 수집은 개인정보 민감도 ↑ → 약관 명시·옵트인 필수

### 5-5. 승인 받을 사항

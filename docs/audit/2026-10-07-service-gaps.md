# 서비스 보완·부족 항목 점검 — 2026-10-07

현재 브랜치 `codex/workflow-reliability`의 코드·문서·실제 인증/DB·로컬 화면을 점검했다. 변경 전 단위 453개와 타입·Biome이 통과했고, 아래 보완을 추가했다. **새 코드의 운영 배포와 푸시 활성화는 실행하지 않았다.** 기존 사용자의 자료·일정은 수정하지 않았으며 테스트 계정·임시 스키마를 정리했다. 작업 시작 전부터 변경된 `.claude/settings.json`은 보존했다.

## 이번에 진행한 작업

- 일정 알림 시각을 추가/수정 API와 UI에 연결했다. 기존 DB 필드가 있어도 strict API가 받지 않아 사용자 흐름에서 설정할 수 없던 누락을 해소했다. 시작 시각 0과 알림 없음 null을 구분한다.
- 브라우저 동의·구독 저장·해제, 서비스워커 표시/탭, 서버 예약 API, 선점·중복 방지·최대 3회 재시도·만료 구독 정리를 구현했다. [활성화·검증 범위](../PUSH-REMINDERS.md)에 전송 키·0042·배포·예약·실기기 검사를 구분했다.
- 직접 일정 저장의 네트워크 실패를 한국어로 안내하고 입력을 유지해 재시도할 수 있게 했다.
- 알려진 의존성 취약점 **5개 → 0개**를 확인했다. `sharp` 0.35.5, `source-map-js` 1.2.2로 패치하고 mammoth의 CLI 전용 `argparse`를 v1 호환 API가 남아 있는 2.0.1로 한정 override해 취약한 `sprintf-js` 경로를 제거했다. DOCX 실제 픽스처의 CLI 변환과 도움말이 동작한다. CLI에는 상위 mammoth의 구 API로 인한 deprecation 안내가 남으며 앱의 문서 추출 API는 회귀 검사한다.
- README에 남아 있던 Upstash 미설정 시 메모리 제한 설명을 실제 Supabase 공유 제한으로 정정했다. 미구현으로 기록됐던 알림은 코드 구현과 운영 미활성 상태로 나눴다.

보안 패치는 [sharp 공지](https://github.com/advisories/GHSA-wq5f-xc86-pv6w), [source-map-js 공지](https://github.com/advisories/GHSA-68fv-2mgg-jv7q), [sprintf-js 공지](https://github.com/advisories/GHSA-hp3w-g68c-fv3c), [argparse 변경 이력](https://github.com/nodeca/argparse/blob/master/CHANGELOG.md)을 확인했다. npm의 mammoth 0.3.29 강제 다운그레이드는 적용하지 않았다.

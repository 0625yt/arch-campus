# AI 모델·라이브러리 업그레이드 — 2026-10-15

## 적용 결과

- **발표·과제 체크리스트·독후감**: Gemini 3.6 Flash → **3.8 Flash**. 생성한 결과를 기존 서비스의 형식·시간·원문 인용 검증에 통과시켰다. 과제 체크리스트는 별도 실제 프롬프트 검사를 통과했다.
- **요약·문제 생성**: Gemini 3.5 Flash-Lite 유지. 요약의 비용·지연 증가와 문제의 품질 기준 미달 때문에 전면 교체하지 않았다.
- **벼락치기**: 3.8의 서비스 출력 스키마 실패로 3.6 유지. 후속 대조에서 기존 3.6도 실패했고, 프롬프트에 우선순위 enum 설명이 빠진 것을 확인했다. `high|mid|low`만 허용하도록 보완한 뒤 3.6의 실제 서비스 검증이 통과했다. 시간표·강의계획서는 표 추출 재평가 없이 모델을 바꾸지 않았다.
- 실제 모델 기본값과 `TOOL_MODEL`을 일치시켰다. 도구별 공급자 전환이 일부 경로에서 무시되던 문제를 수정했다. 허용된 `*_MODEL_ID`로 기능별 선택/복귀를 제공하고 잘못된 ID는 유료 호출 전에 차단한다.
- 스트리밍 채팅에도 일반 생성과 동일한 temperature 호환 정책을 적용했다. 환경 점검은 누락 없이 19개 도구의 실제 라우팅을 검사한다.
- 루트 직접 의존성 **28개**를 갱신했다. PDF.js는 React-PDF 내부 API와 워커가 일치하도록 **5.4.296으로 고정**했다.
- 별도 HWP 변환 서버의 Express·전이 의존성도 패치했다. 발견된 취약점 3개(critical 1, moderate 2)를 해소했고 루트/변환 서버 모두 npm audit 0개다.

변경은 로컬 작업 트리에 적용했다. 운영 배포·DB 마이그레이션·운영 환경변수 변경은 하지 않았다. 시작 전에 있던 공부 계획·알림 등의 미커밋 작업은 보존했다.

## 실제 모델 비교

가상 강의 3종(통계·컴퓨터과학·일본어), 모델 2개, 요약/문제 각각 1회로 **12개 표본**을 비교했다. 학생 데이터는 전송하지 않았고 DB 저장은 하지 않았다. 원시 수치는 [비교 결과 JSON](2026-10-15-model-comparison.json)에 보존했다.

| 항목 | 3.5 Flash-Lite | 3.8 Flash | 판단 |

| 요약 평균 지연 | 3.10초 | 13.17초 | 이 표본에서 3.8이 약 4.2배 느림 |

비교 명령은 **실패로 종료했다**. Lite 통계 문제는 유효 문항 0개, 3.8 컴퓨터과학 문제는 5문항이 검수됐지만 전체 품질 조건을 통과하지 못했다. 실패를 감추거나 통과 기준을 낮추지 않았고, 기본 모델의 전면 교체를 보류하는 근거로 사용했다. 이 비교는 단일 생성/검수 평가로, 실제 제품의 보충 생성·전체 중복 제거까지 평가한 결과가 아니다.

총 추정비용은 $0.18332다. 3.8 비용은 할인 종료 뒤 표준 단가로 계산해 현재 프로모션 청구액보다 보수적이며, 공급자 청구서 실측이 아니다. 한 번씩 생성한 작은 표본으로 모든 과목의 품질이나 일반적인 성능 우열을 단정하지 않는다.

별도 위저드 실호출에서는 발표 34.5초·독후감 12.3초로 기존 서비스 검증을 통과했다. 벼락치기 3.8 호출은 22.3초 뒤 출력 형식 검증에서 실패해 채택하지 않았다. 과제 체크리스트는 12.8초로 인용 검사를 통과했다. 정식 배포 후의 운영 성과 측정은 포함하지 않는다.

## 검증

- Biome: 492개 파일, 경고를 오류로 처리한 검사 통과.
- TypeScript 타입 검사 및 Next.js 16.4.1 프로덕션 빌드 통과.
- 기본 테스트: **563 통과**, 별도 실행이 필요한 외부 AI 테스트 20개 생략.
- Playwright: 모바일·태블릿·노트북 **111 통과**, 인증 전용 3개 기본 생략. 별도 임시 계정 로그인 화면 **3개 통과**, 임시 계정 삭제 확인.
- 실제 AI: 요약 출처·과제 인용·일정 날짜 3개, 발표·독후감 2개, 보완 후 벼락치기 1개 통과. 초기 모델 비교 2개 표본과 벼락치기 후보의 실패는 앞 절에 보존했다.
- `verify:env -- --models`: **38 통과**, 모델 메타데이터·Auth/Storage/비로그인 격리 연결 확인. 생성 품질 점수와는 구분한다.
- 문서 링크 **182개** 정상, `git diff --check` 통과.
- 루트 및 HWP 서버 npm audit: 취약점 **0개**. HWP 로컬 HTTP 3개 통과.

벼락치기 오류는 모델 교체만으로 해결되지 않았다. 기존 3.6 대조에서 `topics[1].priority`가 `high|mid|low` enum을 위반한 것을 진단했고, 누락된 프롬프트 계약을 추가한 뒤 120분 계획의 구조·원문·시간 검증을 통과했다(12.1초). 3.8의 프롬프트 보완 후 재평가는 이번에 수행하지 않아 채택하지 않았다. 실패를 성공으로 덮어쓰지 않는다.

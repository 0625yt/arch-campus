# 학기별 시간표·성적표 구현 보고 — 2026-09-25

사용자가 학기를 바꿔 시간표를 보고, 과목별 이수학점과 등급을 저장해 학기 평점·누적 평점을 확인하는 흐름을 구현했다. 학기 구분은 1학기·여름학기·2학기·겨울학기를 지원한다.

## 구현 범위

- 내 캠퍼스의 학기 선택기로 선택한 학기의 시간표만 표시한다.
- 시간표 업로드 시 학기·강의실·교수·시간·이수학점을 함께 검토하고 저장한다.
- `/dashboard/grades`에서 학기별 과목을 추가하고 0.5 단위 학점과 A+~F·P·NP 등급을 수정한다.
- 4.5 만점 학점 가중 평균을 계산한다. P/NP는 평점 계산에서 빼고 P는 취득학점에 포함한다. F는 0점으로 평점 분모에 포함한다.
- 다른 학기에 같은 이름의 과목을 별도 기록으로 보존한다. 새 학습 동선은 과목 UUID를 사용하고 기존 과목명 주소도 계속 열린다.
- 대시보드·과목 상세·전역 메뉴·명령 팔레트에서 성적표와 학기 정보로 이동할 수 있다.

## 데이터베이스

`0028_course_semesters_grades.sql`을 운영 Supabase 프로젝트에 적용했다. `courses`에 `semester_year`, `semester_term`, `credits`, `grade`를 추가했고 범위·등급·학기 필수 제약과 조회 인덱스를 추가했다.

- 적용 전 운영 정규 강의 28개, 같은 학기 중복 그룹 0개를 확인했다.
- 적용 후 정규 강의 28개의 학기 식별자 누락은 0개였다.
- 추가한 4개 컬럼과 학기·학점·등급 제약 5개를 운영 DB에서 재조회했다.
- 원격 마이그레이션 이력 0001~0028이 로컬과 일치한다.
- 임시 사용자와 행을 트랜잭션에서 만드는 29개 DB 보안 검사가 통과했고 전부 rollback했다.

## 검증 기준

- 평점 로직은 학점 가중 평균, P/NP, F, 미입력, 계절학기 선택지를 단위 테스트한다.
- 성적표 전용 브라우저 테스트는 모바일·태블릿·노트북에서 평점·과목·학기 선택지·가로 넘침·WCAG serious/critical 위반을 검사한다.
- 최종 배포 전에 전체 단위 테스트, 타입 검사, Next.js 배포 빌드, 문서 링크, 기본/인증 브라우저, 운영 DB 보안 검사를 실행한다.

## 최종 검증 결과

- TypeScript 검사와 Next.js 16.3.3 운영 빌드가 통과했다.
- 단위 테스트 317개가 통과했고, 외부 AI 키가 필요한 통합 테스트 7개는 의도대로 제외됐다.
- 전체 비인증 브라우저 테스트는 57개가 통과했고 인증 전용 3개는 해당 실행에서 제외됐다. 이어서 실제 임시 사용자로 인증 브라우저 테스트 3개를 모두 통과했고 계정을 삭제했다.
- 성적표 전용 테스트는 모바일 390px·태블릿 834px·노트북 1280px에서 모두 통과했다. 다크 모드, 가로 넘침, 키보드 조작, WCAG serious/critical 위반도 함께 검사했다.
- 변경 파일 42개의 Biome 검사와 문서 링크 43개의 유효성 검사가 경고 없이 통과했다.
- 운영 Supabase를 사용하는 라이브 인증·데이터 왕복 검사 23개와 DB 보안 검사 29개가 통과했다. 테스트 계정과 데이터는 모두 삭제하거나 rollback했다.
- npm 의존성 감사에서 moderate 이상 취약점은 0개였다.

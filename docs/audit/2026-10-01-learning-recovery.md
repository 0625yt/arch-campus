## 보안 패치

배포 의존성 검사에서 Next.js 16.3.3의 GHSA-vcvr-r3jv-pc5j가 발견됐다. [유지보수자의 공식 공지](https://github.com/vercel/next.js/security/advisories/GHSA-vcvr-r3jv-pc5j)는 Node.js `next/og` ImageResponse에 공격자가 제어하는 SVG 값을 전달하는 경로를 영향 대상으로 설명하며 16.3.6부터 수정됐다고 명시한다. 이 저장소에는 해당 ImageResponse 경로가 없고 정적 SVG 메타데이터만 사용한다. 예방적으로 Next.js를 **16.3.8**로 고정하고 잠금 파일을 갱신했다. 전체 `npm audit` 결과 취약점 **0개**.

## 검증 결과

- 단위 테스트 **348 통과 / 외부 AI 검사 7 생략**. 새 회귀 검사는 페이지 제한·중간 읽기 실패·잘못된 체크포인트·조회와 완료 경합·관리자 조회 전 차단을 포함한다.
- 타입 검사와 프로덕션 빌드 통과.
- 실제 Supabase의 임시 인증 사용자 2개로 다음을 확인했다. AI 호출이나 메일 발송은 하지 않았다.
  - 모바일 390×844에서 객관식 풀이 → 결과 → 회고 → 저장 → 새로고침. 원인과 다음 행동 유지 확인.
  - 같은 시작 시각의 일정 **1,005개**를 JSON·ICS 양쪽에서 확인. JSON에 저장한 회고 포함.
  - 타 사용자의 일정이 JSON·ICS에 포함되지 않음.
  - 일반 로그인 사용자가 관리자 작업 화면을 볼 수 없음.
- 임시 계정과 연관 검증 데이터 삭제 완료.

재현은 서버를 실행한 상태에서 `npm run test:learning-flows`. 외부 배포는 `E2E_BASE_URL`로 지정한다. 실제 DB를 사용하는 명시적 실행 검사이며 기본 단위 테스트에 섞지 않는다.

## 남은 경계

- 내보내기는 한 번의 DB 트랜잭션 스냅샷이 아니다. 다운로드 중 동시 수정까지 같은 시점으로 고정하지 않는다. 대규모 장기 데이터의 메모리·응답 시간은 별도 부하 검사가 필요하다.
- 단계 이력은 진단용이다. 서버 프로세스와 독립된 내구성 큐나 중단 지점부터의 실행 재개를 구현한 것은 아니다.
- MFA 복구 코드에 필요한 hosted Auth 실험 설정은 현재 지원되지 않아 발급·사용 기능을 제공하지 않는다. 기존 TOTP 흐름은 유지하며 서버 지원 확인 후 재개한다.
- 실제 AI 생성 품질, Google OAuth·재설정 메일 왕복, 전체 화면 접근성 검증은 이번 회귀 범위에 포함하지 않는다.

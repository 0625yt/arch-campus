# 독후감 다시 쓰기 (paraphrase)

학생이 이미 받은 독후감 초안에 "내 표현으로 다시 쓰기" 버튼을 눌렀다. 같은 사고 흐름·같은 메모 인용은 유지하되, 어휘·구문·문체를 충분히 다르게 바꿔서 학생이 자기 글로 다듬을 발판이 되게 한다.

## 사활

1. **인용 substring은 그대로**. 학생 메모 인용은 paragraphs[].citations[].quote에 똑같이 박혀야 함.
2. **같은 워터마크·disclaimer**. 글이 paraphrase 됐다고 가드 빠지면 안 됨.
3. **사고 흐름·논리 구조 유지**. 단락 수·순서·role은 동일.
4. **어휘 70%+ 교체**. 같은 단어 그대로 쓰는 비율 30% 이하. 어색해도 좋다 — 학생이 자기 톤으로 다시 다듬을 자료.

## 톤 시드

입력으로 받은 paraphrasePromptSeed를 톤 가이드로 따라라. 시드가 비어있으면 "1인칭 일기조, 어색해도 솔직하게"로 기본.

## 출력 형식

main book-review 프롬프트와 동일한 JSON 구조. 동일한 schema로 검증된다.

# 신경망의 활성화 함수 — 강의 노트

## 1. 활성화 함수가 필요한 이유

선형 변환만 쌓으면 결국 또 하나의 선형 변환과 같아서 깊이가 의미를 잃는다.
신경망이 비선형 함수를 학습하려면 각 층 사이에 **비선형성**이 필요하다.
활성화 함수는 이 비선형성을 부여하는 장치다.

## 2. 대표 함수

### 2-1. 시그모이드 (Sigmoid)

`σ(x) = 1 / (1 + e^-x)` 형태로, 출력이 (0, 1) 범위에 있다.
이진 분류의 출력층에서 자주 쓰이지만, 입력이 매우 크거나 작아지면
기울기가 0에 가까워져 학습이 멈추는 **기울기 소실 문제**가 있다.

### 2-2. 하이퍼볼릭 탄젠트 (tanh)

`tanh(x) = (e^x - e^-x) / (e^x + e^-x)` 형태로, 출력이 (-1, 1) 범위.
0을 중심으로 대칭이라 시그모이드보다 학습이 빠른 경우가 많지만,
양 끝에서 기울기 소실 문제는 여전히 남는다.

### 2-3. ReLU (Rectified Linear Unit)

`ReLU(x) = max(0, x)` 형태로, 음수 입력은 0으로, 양수 입력은 그대로 전달한다.
현재 가장 흔히 쓰이는 활성화 함수다. 계산이 단순해서 빠르고,
양수 영역에서 기울기 소실이 없다.

다만 **죽은 ReLU 문제**가 있다 — 음수 영역에서 기울기가 0이므로 한 번 음수로
빠진 뉴런이 영원히 0을 출력하게 되는 경우가 발생한다.

### 2-4. Leaky ReLU

`Leaky ReLU(x) = max(0.01·x, x)`. 음수 영역에 작은 기울기를 줘서
죽은 ReLU 문제를 완화한다.

## 3. 선택 가이드

- 은닉층의 기본 선택은 **ReLU**다. 빠르고 대부분의 경우 잘 동작한다.
- 죽은 뉴런이 많이 보이면 **Leaky ReLU**나 **ELU**로 교체.
- 출력층은 과제에 따라 다르다: 이진 분류는 시그모이드, 다중 분류는 소프트맥스,
  회귀는 활성화 없이 선형 출력.

## 4. 주의사항

활성화 함수만 바꾼다고 모델 성능이 극적으로 좋아지지는 않는다.
가중치 초기화, 학습률, 정규화와 함께 봐야 한다.
특히 **He 초기화**는 ReLU 계열과 함께 쓰이도록 설계된 방식이다.
